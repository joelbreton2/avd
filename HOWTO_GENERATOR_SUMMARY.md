# How-To Guide Molecule Infrastructure Generator - Summary

## Overview

Created an automated script to generate molecule testing infrastructure for AVD how-to guides, eliminating the need to manually create all the inventory files, data models, and artifact extraction rules.

## What Was Created

### 1. Main Generator Script
**File**: `ansible_collections/arista/avd/extensions/scripts/generate_howto_molecule.py`
- **Lines**: 408
- **Language**: Python 3
- **Dependencies**: PyYAML

**Features**:
- Generates complete molecule infrastructure from a YAML configuration file
- Creates inventory structure (hosts.yml updates)
- Generates L3 leaf switch configurations
- Creates port profiles, network ports, or connected endpoints
- Generates network services (VLANs/VRFs)
- Updates artifacts.yml with extraction rules
- Provides detailed logging and error handling
- Supports both network_ports and connected_endpoints approaches

## How It Works

### Input: YAML Configuration File

```yaml
guide:
  name: "Network Ports"
  prefix: "HTNP"
  docs_path: "../../../../../../docs/howto/network_ports"

switches:
  - name: htnp-leaf1a
    mgmt_ip: 172.16.1.201/24

port_profiles:
  - profile: PP-WebServer
    mode: access
    vlans: "100"

network_ports:
  - switches: [htnp-leaf1a]
    switch_ports: [Ethernet10-15]
    profile: PP-WebServer

network_services:
  - name: TENANT_HTNP
    vrfs:
      - name: VRF_WEB
        svis:
          - id: 100
            name: WebServers

artifacts:
  - file: inventory/intended/configs/htnp-leaf1a.cfg
    sections:
      - header: "interface Ethernet10"
    artifact: "htnp-leaf1a-webserver-ports.cfg"
```

### Output: Complete Molecule Infrastructure

```
molecule/howto/
├── inventory/
│   ├── hosts.yml (updated with new fabric group)
│   └── group_vars/
│       ├── HTNP/
│       │   ├── port_profiles.yml
│       │   ├── network_ports.yml
│       │   └── network_services.yml
│       └── HTNP_L3_LEAFS/
│           └── l3_leafs.yml
└── artifacts.yml (updated with extraction rules)

docs/howto/network_ports/
└── artifacts/ (directory created, files generated by molecule)
```

## Usage Workflow

### 1. Create Configuration
```bash
cd ansible_collections/arista/avd/extensions/scripts
cp examples/howto_network_ports_example.yml my_guide.yml
# Edit my_guide.yml
```

### 2. Generate Infrastructure
```bash
python3 generate_howto_molecule.py --config my_guide.yml
```

### 3. Run Molecule Tests
```bash
cd ../molecule/howto
ANSIBLE_COLLECTIONS_PATH=/path/to/avd ansible-playbook converge.yml -i inventory/hosts.yml
ANSIBLE_COLLECTIONS_PATH=/path/to/avd ansible-playbook side_effect.yml -i inventory/hosts.yml
```

### 4. Update Documentation
Reference artifacts in markdown:
````markdown
```cli title="Web Server Ports"
--8<--
avd/docs/howto/network_ports/artifacts/htnp-leaf1a-webserver-ports.cfg
--8<--
```
````

### 5. Commit
```bash
git add .
git commit -m "Feat: Add <guide-name> how-to guide molecule infrastructure"
```
